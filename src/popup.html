Mori Browser Extension

Opt-in browser activity capture companion for Mori.

Collected

  • Active tab changes
  • Committed navigations
  • Current normal window and tab metadata

Not collected

  • Page contents or DOM
  • Passwords or form input
  • Cookies or account state
  • Browser history import

Disclosure

When capture is on, Mori receives sanitized browser activity on this computer. URLs keep origin and path only; query strings, fragments, credentials, page contents, form input, cookies, and incognito tabs are not sent.
